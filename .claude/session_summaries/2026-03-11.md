## TODO Next Session: Switch Production to Netlify (to enable private repo)

**Why:** GitHub Pages requires a public repo on the free tier. Netlify serves private repos for free.

**Steps:**
1. In Netlify dashboard, set the production branch to `master`
   - Site settings → Build & deploy → Continuous Deployment → Production branch: `master`
2. Add your custom domain in Netlify
   - Site settings → Domain management → Add custom domain → `matthewkperez.com`
3. Update DNS records at your domain registrar (wherever matthewkperez.com is registered):
   - Remove the existing GitHub Pages `A` records (185.199.108-111.153)
   - Remove the `CNAME` for `www` pointing to `matthewkperez.github.io`
   - Add a Netlify `A` record: `75.2.60.5` (or use Netlify's DNS nameservers for easier setup)
   - Add a `CNAME` for `www` pointing to `matthewkperez.netlify.app`
4. Enable HTTPS in Netlify (automatic via Let's Encrypt once DNS propagates)
5. Make the GitHub repo private (Settings → Danger Zone → Change visibility)
6. Optionally disable GitHub Pages (Settings → Pages → Source → None)

**Notes:**
- DNS propagation takes up to 48h but usually ~30min
- The `CNAME` file in the repo is only needed for GitHub Pages — can be removed after switching
- Netlify free tier supports custom domains and HTTPS at no cost
- `staging` branch continues to deploy to `staging--matthewkperez.netlify.app` as before
